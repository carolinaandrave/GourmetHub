# Gourmet Hub

Proyecto desarrollado para la Evaluación Parcial 1 de la asignatura Desarrollo Fullstack II.

Gourmet Hub es una tienda online especializada en productos gastronómicos de alta calidad y talleres de cocina. El sitio permite registrar usuarios, informar restricciones alimentarias, revisar productos y utilizar un carrito de compras.

## Objetivo

Desarrollar una solución web responsiva utilizando HTML5, CSS3 y JavaScript, aplicando validaciones, manipulación del DOM, almacenamiento local y control de versiones con GitHub.

## Funcionalidades

- Página principal responsiva.
- Navegación entre las diferentes páginas.
- Catálogo de productos generado con JavaScript.
- Detalle dinámico de productos.
- Carrito de compras con localStorage.
- Registro con validaciones personalizadas.
- Selección de restricciones alimentarias.
- Creación dinámica de recetas o cursos de interés.
- Inicio de sesión.
- Formulario de contacto.
- Blog con dos publicaciones.
- Panel administrativo.
- Mantenedor de productos.
- Mantenedor de usuarios.
- Regiones y comunas cargadas mediante JavaScript.
- Validación de RUN chileno.
- Control de stock crítico.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server
- Git
- GitHub
- localStorage

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Instalar la extensión Live Server.
4. Abrir el archivo `index.html`.
5. Seleccionar Open with Live Server.

## Validaciones principales

El registro verifica el nombre, correo, contraseña, confirmación, restricciones alimentarias y cursos de interés.

La contraseña debe tener al menos 10 caracteres, dos letras mayúsculas, una letra minúscula, un número y uno de los símbolos permitidos.

El formulario de contacto comprueba los campos obligatorios y limita el comentario a 500 caracteres.

El formulario administrativo de usuarios valida el RUN, correo, región, comuna, perfil y dirección.

## Control de versiones

El proyecto utiliza GitHub para registrar el avance mediante commits claros y descriptivos.
